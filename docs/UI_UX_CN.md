# UI 与交互设计规范

[English](./UI_UX.md) | **简体中文**

芽米学习伙伴面向两个互补场景设计：
1. **家长端 Web（`/guardian`）**——清爽、低噪音、一眼扫视的日常统筹工作台；
2. **ESP-Mosaico S31（480×480 AMOLED）**——放在孩子书桌上的温暖语音伙伴与萌宠激励屏。

---

## 1. 家长端 Web ·「晨光白瓷」三栏工作台

### 设计 Token

| Token | 色值 | 用途 |
|---|---|---|
| `--md-sys-color-surface` | `#FFFFFF` | 主工作区纯白画布 |
| `--md-sys-color-surface-container-low` | `#F7F9FC` | 左侧浅灰蓝导航栏 |
| `--md-sys-color-surface-container` | `#F4F6FA` | 卡片内嵌行、KPI 块、表扬摘要 |
| `--md-sys-color-outline-variant` | `#E3E8EF` | `1px` 精准边框与三栏分割线 |
| `--md-sys-color-primary` | `#1A73E8` | 主按钮、激活态、成长日历今日高亮 |
| `--md-sys-color-primary-container` | `#E8F0FE` | 导航激活胶囊、信息标签 |
| `--md-sys-color-secondary` | `#137333` / `#E6F4EA` | 已完成作业、已确认表扬 |
| `--md-sys-color-tertiary` | `#B06000` / `#FEF7E0` | 家长待办与待核对状态 |
| `--md-sys-color-on-surface` | `#1F1F1F` / `#5F6368` | 高对比度正文与次级文字（WCAG AA ≥ 4.5:1） |
| **字体** | `Plus Jakarta Sans`, `Noto Sans SC` | 现代几何西文 + 清晰中文排印 |
| **图标** | 24×24 线性 SVG（界面框架零 Emoji） | 统一克制的视觉语言 |

### 响应式布局拓扑
- **桌面端（`≥ 1180px`）**：Google Workspace 风格三栏布局——左侧 `224px` 导航栏 + 中间主工作区 + 右侧 `368px` 常驻上下文栏（实时展示 **成长日历** 与 **教师表扬看板**）。
- **平板 / 移动端（`< 1180px`）**：单栏主视图 + 底部无障碍导航条（`role="tablist"`）。
- **右上角全局工具区**：孩子档案切换 Popover、**家长账号**弹窗（`<dialog id="account-dialog">`）与 **帮助**弹窗（`<dialog id="help-dialog">`，收纳 Mosaico 按键与语音说明）。

### 4 标签页信息架构

1. **今日（`今日`）**——严格 5 段顺序：
   1. **今日作业**（支持家长一键标记完成/取消、折叠式手动补充；自动排除家校通知）
   2. **待办**（需家长签字的家校通知与待提交确认项）
   3. **预习与复习**（合并展示复习巩固与明日预习）
   4. **自定义任务**（完整生命周期：按 `每日重复 / 工作日 / 仅今日` 新增、打卡连胜统计、按状态筛选、暂停/恢复、编辑、删除）
   5. **教师今日反馈**（班级群表扬一键确认记入成长）
2. **成长（`成长`）**——精简聚合架构（移除冗余流水表）：
   1. **成长日历**：按月热力图展示完成度，明确标出 **今天（`今`）** 与 **回到今天**，点击任意日期查看详情并一键联动 **查看当天对话**
   2. **教师表扬与课堂表现看板**：统计看板（累计 / 本月 / 高频学科）+ 按学科筛选 + 详细卡片（学科 / 老师 / 日期 / 来源 / 原话 / 家长备注）+ 折叠式手动补录
   3. **教材学情与知识点**：紧跟真实年级与各科教材目录追踪单元掌握度 + 已解锁方法卡
   4. **习惯养成统计**：自动聚合近 7 天作业完成率与自定义任务连胜天数
   5. **情绪晴雨表**：无感日常情绪信号统计 + 亲子沟通建议（非临床诊断）
   6. **学习记忆 & 语音对话记录**：面向家长的通俗记忆管理（零数据库术语）+ 按本地时区精确筛选的语音对话记录（`今天 / 昨天 / 全部` + 日期选择器）
3. **技能（`技能`）**：按学生独立启停 5 大 AI Skill + 语音听写快捷入口。
4. **设置（`设置`）**：学生档案与分科教材版本、Mosaico 6 位配对码绑定、钉钉集成配置（`AppId / AppSecret / 班级群 ID / 家庭私群 Webhook` + 一键 **立即同步钉钉**）、《芽米宠物小屋》1:1 实时互动。

## 2. ESP-Mosaico S31（480×480 AMOLED）桌宠与语音体验

### 交互与文案原则
- **纸笔为主、屏幕轻打扰**：孩子始终在纸面写作业，Mosaico 每次只播一句清晰提示，专注时不播无意义循环动画。
- **表扬过程而非贴标签**：复述孩子做过的具体行为（「你先画了示意图」），不说空泛评价（「你真聪明」）。
- **苏格拉底分级启发**：确认题意 → 孩子先说一步 → 一条线索 → 示意图 → 类似例题 → 回到纸面，绝不直接剧透最终答案。

### 极简双按键规则（硬件级防误触互斥锁）
- **长按右键（≥ 0.35 秒）**：按住说话，松开即发（或直接语音唤醒）。
- **长按左键（≥ 0.45 秒）**：一键进入 / 退出《芽米宠物小屋》。
- **短按左/右键**：切换作业条目，或在宠物小屋中选餐并抛物线投喂。

### 《芽米宠物小屋》情感激励闭环
- **9 只 4×4 逐帧动态萌宠**（奇幻星灵 / 萌趣伙伴 / 星际潮玩三大系列）+ 4 级可升级小窝场景，与家长端 Web 拍立得卡片 1:1 实时同步。
- **正向学习激励**：完成学习任务赚取宠粮币（每项约 `+20` 币），喂食与摸摸互动提升饮食与开心星级。
- **温和责任感机制**：连续 3 天未照顾进入饥饿委屈态；连续 7 天未照顾触发离家出走，需用 `100` 币（约 5 项学习任务）温情召回。
